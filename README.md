# PyScraper Pro - Lead Scraper & Cold Email Outreach Bot

Built for **Irtaza Khalid** (Flutter & Mobile Developer) to find potential clients, extract business emails & contacts, generate personalized pitches, and send cold email campaigns.

## Quick Start

### 1. Launch Web Dashboard
```bash
.venv/bin/streamlit run app.py
```
Open `http://localhost:8501` in your browser.

### 2. Run CLI Lead Scraper
```bash
.venv/bin/python cli.py --url https://example.com --export csv --out leads.csv
```

### 3. Run Verification Suite
```bash
.venv/bin/python demo_app.py
```
